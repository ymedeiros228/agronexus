# ADR 0001 — Nicho piloto: soja no Maranhão

- Status: aceita (2026-10-03)

## Contexto
O ZIP original descreve uma plataforma para toda a agricultura. Sem um nicho, catálogo, unidades e linguagem ficam genéricos. A pessoa responsável pelo produto está no Maranhão, onde a região produtora é de soja, e tem acesso a uma estagiária de agronomia que trabalha numa empresa do setor de genética de soja.

## Decisão
O piloto é **soja, no Maranhão**. Catálogo de estágios (V/R), pragas, doenças e operações nasce para soja de sequeiro.

## Consequências
- Pecuária fica fora do produto por enquanto.
- Chuva (pluviômetro) vira dado central; sensores e IoT ficam para depois.
- Outras culturas só entram depois do piloto validado.
